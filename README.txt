けいさんバトル v2

親子で使う電子計算カードです。
子ども：問題を見て答えを声に出す
親：答えを確認して「つぎ！」を1回タップ

・4セット、合計180問
・問題セットは複数選択可能（初期状態は全て未選択）
・複数セット選択時も常にシャッフル
・答えの表示なし／答え入力なし
・かずチャレンジ：10 / 15 / 20
・じかんチャレンジ：20 / 30 / 40秒
・きろくチャレンジ：20問固定、開始から20問目のタップまで計測
・記録は選択した問題セットの組み合わせごとにTOP10を保存
・localStorage使用
・PWA用 manifest / service worker 同梱

index.html をブラウザで開いてください。
Android Chromeでは対応環境ならホーム画面に追加してアプリ風に利用できます。
